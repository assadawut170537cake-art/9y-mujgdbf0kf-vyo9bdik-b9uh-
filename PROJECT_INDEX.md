# Mark-LV Project Index

## Project Overview
Mark-LV is a Python-based agent/automation system with a modular architecture.

## Project Structure
```
Mark-LV/
├── main.py (116KB) — Entry point
├── ui.py (252KB) — UI layer
├── requirements.txt — Dependencies
├── setup.py — Package setup
├── readme.md — Project documentation
├── .gitignore — Git ignore rules
├── actions/ — Action handlers
├── config/ — Configuration files
├── core/ — Core logic
├── dashboard/ — Dashboard UI
├── memory/ — Memory/state management
└── plugins/ — Plugin system
```

## Core Components

### Main Entry Point (main.py)
- 116KB, primary application entry
- Handles initialization and orchestration

### UI Layer (ui.py)
- 252KB, user interface implementation
- Dashboard and interaction components

### Actions Module
- Action handlers for system operations
- Modular action definitions

### Core Logic
- Main business logic and processing
- Core algorithms and workflows

### Dashboard
- UI dashboard components
- Monitoring and visualization

### Memory/State
- State management
- Memory persistence layer

### Plugins
- Plugin system for extensibility
- Third-party integrations

## Configuration
- config/ directory for all configuration
- Environment-based settings

## Dependencies
- requirements.txt lists all Python dependencies
- setup.py for package installation

## Key Features
- Agent/automation system architecture
- Modular plugin-based design
- State/memory persistence
- Dashboard UI
- Action handler system

## Usage
1. Install dependencies: `pip install -r requirements.txt`
2. Run main: `python main.py`
3. Configure via config/ directory
