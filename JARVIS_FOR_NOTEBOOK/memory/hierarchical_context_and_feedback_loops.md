# แนวทางสถาปัตยกรรม Hierarchical Context และ Automated Feedback Harness

## 1. การจัดการบริบท (Context Management)
- ห้ามก๊อปปี้โค้ดยาวๆ แปะลงในแชทโดยไม่จำเป็น ให้ดึงผ่าน File Search / Glob / Grep เท่าที่จำเป็น
- โครงสร้างบริบทแบบลำดับชั้นช่วยลดการใช้ Token และเพิ่มความแม่นยำ 3x-5x

## 2. กระบวนการตรวจสอบและกู้คืน (Verification & Safe Rollback)
- ห้าม Merge โค้ดหรือบันทึกทับไฟล์เดิมหาก Unit Test ไม่ผ่าน
- เมื่อพบความผิดพลาด ให้ถอยกลับจุดเดิม (Rollback) ทันที 100% แล้วสกัดข้อผิดพลาดเป็นบทเรียนบันทึกลงไฟล์
