# J.A.R.V.I.S. MASTER CONTEXT & ARCHITECTURE (Hierarchical Context System)
- LOCAL-FIRST & ZERO-LEAK: ประมวลผลบนเครื่อง Local 100% ปลอดภัย ไม่ส่งโค้ดขึ้นเทรนโมเดลภายนอก
- CONTEXT HIERARCHY:
  1. Root Config: ยึดถือ Master Manifest, Project Passport และกฎส่วนกลาง 100%
  2. Sub-Directory Context: โหลดบริบทเฉพาะโฟลเดอร์เมื่อเข้าปฏิบัติการในส่วนนั้นๆ
  3. User Personal Memory: เก็บ Preference ประจำตัวผู้ใช้งาน (คุณอัษฎาวุธ)
- EXECUTION WORKFLOW: 3-Phase Execution (Brainstorm ➡️ Plan ➡️ Approve ➡️ Code)
- CONTINUOUS VERIFICATION: รันผ่าน Automated Test Harness ก่อนส่งมอบงานเสมอ
- SINGLE SOURCE OF TRUTH: ซิงก์ฐานความรู้และ Memory Vault บน Google Drive และ Local DB
